# Seller marketing tools

Seller dashboard → Marketing Tools opens Store Upgrade, Purchase History, and Seller Level. The Add Product page also includes the shared warehouse: selecting an item fills its full fields and category path, and the existing Add Product action creates the seller copy. Review edits and publication flags are retained; importing does not change the shared warehouse original.

Initial promotion packages match the supplied screenshot: International $666.66 / 30 days / 10 slots, Overseas $299.99 / 30 days / 5 slots, Standard $199.99 / 30 days / 2 slots. Activation is a one-time manual purchase, with no automatic recurring charge. Active sellers can choose their own published products for the storefront's labeled promoted collection. Expired packages stop serving promotions. Renewing the same package extends its current expiry; upgrading starts a new 30-day period.

All six seller level selling prices are $0.00, as shown in the screenshot and confirmed by the owner. Operating-funds requirements are separate reference fields, not amounts charged as upgrade fees. Level requests need administrator approval and do not ask for a fabricated zero-value coin transfer. Approved levels have no expiry; a seller cannot purchase a lower/equal level. Reference traffic/profit/bonus figures are presented as program reference values, not guaranteed results or automatically credited balances. This change does not create referrals, external traffic, automatic bonuses, shipments or blockchain transfers.

Paid requests follow: requested → awaiting_payment → proof_submitted → approved/rejected. The administrator enters the wallet, network and USD-per-coin rate. Coin amounts are calculated with integer arithmetic and rounded upward to eight decimals. A known request's USD fee is immutable. New fees configured in the admin panel affect future requests only. Sending a wallet or submitting a receipt does not activate the package. Approval requires independent verification and a transfer reference. Reusing an approved coin/network/transfer reference is rejected. Reviews are serialized, record the administrator, and create one entitlement per request. Seller cancellation is available before payment instructions.

Receipts are PNG/JPEG images up to 2 MB, validated by file signatures and stored in the existing private Supabase Storage bucket. Only the owning seller or an administrator can retrieve them. No secrets or real wallet addresses are committed. No new paid service or external payment processor is enabled.

Admin dashboard → Marketing & seller upgrades contains requests, payment instructions, receipt links, approval/decline controls, and editable fees. Sellers receive existing in-app notifications for quotes and approval. Purchase History refreshes in the background and shows congratulations only after approval.

`npm test` covers the workflow, authoritative prices, retries, roles, private receipts, free approval, paid approval, duplicate references/activations, expiry and promotion slots. Browser checks additionally exercise the responsive pages, request/receipt/congratulations flow, warehouse autofill, sidebar dropdown and admin panel.
